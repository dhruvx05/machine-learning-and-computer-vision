# Pattern and Visual Recognition

This repository contains implementations of core machine learning and image processing algorithms using Python.

It focuses on supervised learning, unsupervised learning, clustering techniques, and image segmentation methods commonly used in computer vision and pattern recognition systems.

---

## 🚀 Implemented Algorithms & Techniques

### 📊 Regression
- Linear Regression
- Model evaluation using Mean Squared Error (MSE) and R² Score

### 📈 Classification
- Logistic Regression
- Performance metrics: Accuracy, Precision, Recall, ROC-AUC

### 🔍 Clustering
- K-Means Clustering
- Elbow Method for optimal cluster selection
- Dataset grouping and pattern discovery

### 🖼 Image Segmentation
- K-Means based color segmentation
- Global Thresholding
- Otsu’s Thresholding
- Sobel Edge Detection
- Canny Edge Detection
